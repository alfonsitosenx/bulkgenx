# BulkGenX — AI Bulk Image Generator

Windows app by Excess Pro Net LLC that generates hundreds of AI images from one
prompt across six providers, and shows what every image costs before you spend.

**This repository hosts the downloads only — it contains no source code.**

## Download

**[Latest release — BulkGenX-Setup-1.0.2.exe](https://github.com/alfonsitosenx/bulkgenx/releases/latest)**

One installer for both editions: it runs as the free edition until you enter a
licence key.

## Requirements

- Windows 10 or 11, 64-bit
- An API key from at least one supported provider: Google Gemini, OpenAI,
  Stability AI, Replicate, OpenRouter or Alibaba Cloud
- Internet for image generation and licence activation

## Free and Pro

- **Free:** all six providers, up to 5 images per run, every style preset,
  live pricing and spend tracking, Auto-detect and Grid splitting
- **Pro:** up to 500 images per run and the AI Extract / AI Vision splitter —
  $7.99/month, $49/year or $99 lifetime (3-PC licence: $89/year or $179 lifetime).
  See [pricing](https://excesspronet.com/softwares/bulkgenx/#pricing)

You pay your AI providers directly, at their prices. BulkGenX adds no markup.
